# ALILAGUNA｜详细设计与 AI 协作工作流

以概念音乐影像连接叙事、拍摄、剪辑、调色和 VFX。我负责影像导演及视觉呈现；本次 AI 协作帮助作品复盘、资料组织和数字案例展示。原作品归档保留，不进入求职主页精选。

  N3["我评审画面和节奏"]:::human

## 1. 从音乐情绪组织影像

把概念、镜头与画面节奏放在一起考虑，建立影像方向和视觉基准。导演判断决定内容如何与声音形成关系。

## 2. 整理拍摄与视觉方案

以既有制作资料核对叙事、构图、色彩和镜头安排。AI 协作帮助当前资料的章节梳理和说明，原拍摄与创作职责保持清晰。

## 3. 完成拍摄、剪辑与 VFX

通过拍摄、剪辑、调色和特效组织连续影像，专业制作控制素材节奏、视觉衔接和最终画面。

## 4. 人工评审画面与声音

对照音乐检查叙事、切点、调色一致性和特效强度。视觉判断贯穿镜头选择、后期调整与最终排版。

## 5. Codex 组织数字案例

当前作品集由 Codex 辅助整理图像、影片和职责说明。我选择代表镜头与观看顺序，让完整创作过程能够被浏览。

## 6. 归档与可追溯复盘

原说明和素材按原内容保留，新的工作流补充在归档目录中。通过原影片、图像与提交记录查看专业制作的实际产出。

## 审美与专业评审

| 评审维度 | 我的专业判断 |
| --- | --- |
| **音乐与叙事** | 镜头与剪辑节奏对应音乐情绪。 |
| **后期品质** | 调色、特效与排版保持统一。 |
| **原创制作** | 保留原资料、导演职责与过程记录。 |

## 操作、输入输出与指令控制

我先用完整的任务说明建立上下文：交代项目目标、参考资料、审美方向、实现约束、输出格式与验收标准，让 ChatGPT 和 Codex 理解要完成什么。得到初步方案或原型后，我再以精准的短指令逐轮控制修改，明确本轮改什么、保留什么，并对照实际结果继续判断。**完整指令建立方向，短指令控制细节，专业判断决定交付。**

| 操作阶段 | 输入 | 我的控制与 AI 协作 | 输出与验收 |
| --- | --- | --- | --- |
| 建立方向 | 音乐、镜头、拍摄与后期资料 | 我定义设计目标，AI 辅助当前资料整理 | 明确主题与范围，核对原资料 |
| 组织方案 | 研究、参考与既有成果 | 我决定结构、视觉与专业约束 | 方案与任务；检查逻辑是否成立 |
| 专业制作 | 明确的设计方案 | 原作依照专业工具和团队分工完成 | 模型、场景或体验；由我核对效果 |
| 数字原型 | 作品资料、完整页面说明 | Codex 辅助当前网页与交互呈现 | 可浏览案例；核对原项目表达 |
| 精准迭代 | 页面、录屏与具体问题 | 短指令限定 构图、切点、调色与特效强度 | 局部更新；与前轮和原参考对照 |
| 验收交付 | 通过评审的内容与实现 | 我核对完整性、职责和观看顺序 | 影片、图像、原说明与归档 |

本段说明原项目的专业制作与当前 AI 辅助数字案例整理。修改前保留已有方案，以明确的修改对象和验收条件控制本轮结果。
