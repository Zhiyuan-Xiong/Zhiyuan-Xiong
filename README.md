## 项目目标

一段从现实走向死亡边界、再返回现实的旅程。地铁成为当代渡船：失灵的指示牌与扭曲的时间，让稳定的日常逐渐松动。影像将实拍、数字特效与三维空间相结合，通过倒放、镜像与分屏，使现实与虚拟世界彼此渗透。

## 我的贡献

影像导演：拍摄、剪辑、调色、VFX 与排版

完成阶段：已完成概念音乐影像

现有产出：完整 MV、概念拼贴、音乐分析、十二格分镜与制作过程
